# Codex 积分购买：官方入口在哪、积分怎么算，国内没有外卡时的替代方案

搜"Codex 积分购买"的人，遇到的问题其实就两类：一是在 ChatGPT 里翻遍设置也没找到买积分的按钮；二是找到了，但付款那一步过不去。

这两种情况要分开处理。第一种是资格问题，积分入口不是所有账号都开放；第二种是支付问题，账号有入口、卡刷不过去。下面把官方的购买规则、计费方式、限制条件讲清楚，再说说国内用户在没有国际信用卡时通常怎么绕。

## 先把三样东西分清楚，别买错

很多人以为"Codex 积分"是一个可以到处买的产品。实际上官方体系里同时存在三种长得像的余额，用途完全不同。

| 名称 | 是什么 | 怎么获得 | 用在哪 |
| --- | --- | --- | --- |
| ChatGPT 套餐 | 按月订阅，含一定用量额度 | ChatGPT 内订阅 | Codex 的用量包含在套餐额度里 |
| Codex 积分（Credits） | 套餐额度用完后的按量补充 | 账号内购买 | Codex，以及部分代理式功能 |
| API 余额 | 开发者账单 | 开发者平台充值 | 走 API Key 的程序化调用 |

最容易踩的坑是把 API 余额当成 Codex 积分买。两者不互通，API 余额不会补上你在 Codex 里的额度。

## 官方购买入口在哪

积分入口不会一直显示，它跟你的用量状态有关。达到套餐用量上限后，Codex 里会出现"添加积分"的选项；没有撞到上限，界面上通常看不到这个按钮。

购买路径有两条：

1. ChatGPT 网页版的 **设置 > 用量** 里查看余额和购买
2. Codex 应用里的 **用量与账单**（Settings > Usage > Credits），网页版和桌面应用都可以

合资格用户还能打开自动充值。规则是设一个最低余额和目标余额，余额掉到最低值以下，系统用已登记的默认付款方式自动补到目标值，可以额外设每月消费上限。如果开启的时候余额已经低于最低值，可能立刻就会扣一次。

积分余额不是所有功能共用一套账，但目前可支持的功能确实共享同一个余额池——Codex、ChatGPT 工作、Excel 这些走的是同一份积分。这意味着你在网页端用掉的，和命令行里用掉的，从同一处扣。

## 买之前必须知道的几条硬规则

这几条官方写在帮助文档里，性质属于"买了就不能反悔"，比价格更值得先看。

- **不可退款。** 除非法律另有要求，积分购买后不支持退款。
- **有效期 12 个月。** 从购买日起算，过期未用完的部分作废，不结转。
- **不可转让。** 没有现金价值，不能转售、不能当礼物送人。
- **不等于 API 积分。** 再强调一次，因为误解的人不少。
- **余额可能变成负数。** 如果任务开始时余额还是正的，但执行过程中被并发任务耗光，余额会先欠着。之后你买的积分或自动充值，会先抵消负数部分，再变成可用额度。

另外，Free 和 Go 套餐只有部分账号开放购买积分。如果你的设置页里根本没有相关入口，那不是你不会找，是账号还没放开。可购买的数量、价格、付款方式和消费上限会因账号、地区、套餐而不同。

> 购买积分不会改变你的套餐，也不会提高套餐本身包含的用量上限。它只是在额度之外多开一条按量付费的路。

## 价格怎么算：官方给的是费率卡，不是点数包

这里要说清楚一件事：官方没有"500 点 20 美元"这种固定充值包，积分是按 token 折算的，不同模型费率不同。官方费率卡上给了一个便于估算的参考值——GPT-5.5 平均每条消息大约消耗 5 到 45 积分。区间这么宽，是因为任务复杂度差别太大：问一句和让它改一整个模块，消耗不在一个量级。所以"该买多少积分"很难一次算准，更现实的做法是先买一小笔，跑一周看消耗速度。

关于更激进的付费方式，公开报道里出现过一条：有用户在周额度用尽后看到"付 8 美元立即重置"的按钮，点击后额度恢复满格。OpenAI 方面对此的回应是正在探索让触顶用户追加购买的机制。但这是媒体基于用户截图整理的报道，没有对应的官方公告页，$8 这个数字不要当成确定价目来看。

## 国内用户的卡点不在"想不想买"，而在"能不能付"

Codex 积分购买这件事，对一部分人来说根本不是价格问题。

付款需要账号本身具备官方订阅条件，需要一张能过风控的国际卡。国内银行发行的外币卡在 OpenAI 场景里被拒是常态，原因往往不是余额，而是发卡地区、账单地址、支付通道和 IP 环境的综合判断。更麻烦的是，有些账号即使有卡，设置页里也不显示积分入口。

所以搜索"Codex 积分购买"的人里，相当一部分真正想解决的问题是：**周额度快见底了，手头没有能付的卡，怎么把额度续上。**

可选的路径有这么几条，按成本从低到高排：

1. **等自动重置。** 零成本，代价是干等，赶进度的时候基本不可行。
2. **用攒下来的重置机会。** 合资格账号可以通过邀请等途径获得重置次数，这部分不需要额外付费。
3. **在账号内买积分。** 账号有入口、支付方式能过的话，这是最干净的办法。
4. **升到更高档套餐。** 长期高频、每周都撞顶的人，比反复买积分划算。
5. **通过代充平台开通订阅。** 就是没有外卡、账号又没有官方支付条件时的那条路。

## 到底该买积分、升套餐，还是走代充

判断标准不是价格绝对值，而是你撞限额的频率。

**一个月撞一次顶**，等重置就行，不值得为一次卡顿买积分。

**一个月撞两三次**，如果你账号里有积分入口而且付款过得去，直接在账号内买积分最省事。积分跨功能共用，Codex、ChatGPT 工作、Excel 消耗的是同一份余额，不会浪费。

**每周都撞顶**，算一下账：反复买积分的累计支出通常会超过直接上 Pro 的差价。这时候升档比补积分划算。

**翻遍设置找不到入口，或者卡片一直被拒**，那问题不在选择上，在支付通道上。先解决订阅能不能开通，再谈额度够不够用，顺序反了只会一直卡在付款页。

一个现实提醒：先确认自己的钱花在哪个层面。如果你需要的是 API 按 token 计费的额度，别在 ChatGPT 侧买积分；如果你需要的是 Codex 的周额度补充，那 API 余额一点忙都帮不上。

## 常见问题

**积分可以送给别人吗？**
不可以。官方明确积分不可转让、无现金价值、不能转售或赠送。朋友过生日想送 AI 额度，这条路走不通。

**买错了能退吗？**
除法律要求的情况外，积分不支持退款。这是一条单向的交易，买之前想清楚。

**积分会过期吗？**
会。购买后 12 个月内有效，过期作废，不结转。

**Free 和 Go 用户能买吗？**
目前只有部分账号开放。设置和用量页里没有入口，就是还没轮到你。

**第三方平台卖的"Codex 积分"是真的官方积分吗？**
不是。官方积分绑定账号、不可转让，第三方卖的通常是订阅开通、共享额度或独立的按量调用通道。看到"代充官方积分"这类说法，先按这个机制判断一下。

**Codex 积分的消耗速度怎么估？**
官方费率卡给的参考是 GPT-5.5 平均每条消息 5 到 45 积分，区间很宽，取决于任务复杂度和你选的模型档位。轻量模型干杂活、控制推理强度、能用命令行非交互模式就别开并行任务，这些都会明显减慢消耗。
